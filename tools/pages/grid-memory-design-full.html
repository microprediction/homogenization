Optimal grid weights discard a prefix

On any fixed irregular grid, minimum stationary path variance under an exponential start-memory budget has explicit breakpoints and weights. Computing the optimum needs only a linear number of arithmetic operations, without a dense covariance matrix.

Setup and the quantity being optimized

Use relaxation-time units: $0=t_0<\cdots<t_{n-1}=R$, $n\ge2$. Let $X_t\in\{0,1\}$ have generator $Q=\left(\begin{smallmatrix}-p&p\\1-p&-(1-p)\end{smallmatrix}\right)$, $p\in(0,1)$, and stationary law $(1-p,p)$.

For deterministic nonnegative weights $w_j$ summing to one, define $A_w=\sum_jw_j(X_{t_j}-p)$, $l_j=e^{-t_j}$, and $K_{ij}=e^{-|t_i-t_j|}$. Then exactly

$$\mathbb E_i A_w=(i-p)l^Tw,\qquad \operatorname{Var}_\pi A_w=p(1-p)w^TKw.$$

For $S=\mu A_w+\sigma Z$, independent $Z\sim N(0,1)$ and $\sigma>0$, a common rate-one Bernoulli refresh couples start $i$ to stationarity, giving $\sup_q|F_i(q)-F_\pi(q)|\le |\mu||i-p|l^Tw/(\sigma\sqrt{2\pi})$. Thus a bound on $l^Tw$ controls exact mean memory and a population coverage-error bound, not actual coverage error.

The design problem is $E_*(\ell)=\min\{w^TKw:w\ge0,\ \mathbf1^Tw=1,\ l^Tw\le\ell\}$ for $0\le\ell\le1$. It is infeasible below $l_{n-1}=e^{-R}$; equality permits only the terminal observation, with energy one.

Information and memory breakpoints

Write $\rho_j=e^{-(t_{j+1}-t_j)}\in(0,1)$ and $I_k=1+\sum_{j=k}^{n-2}(1-\rho_j)/(1+\rho_j)$. These suffix information values are obtained by one backward cumulative sum.

$$B_{-1}=I_0^{-1},\qquad B_k=\frac{l_{k+1}}{I_k(1+\rho_k)-1}\quad(0\le k\le n-2).$$

The breakpoints strictly decrease from $B_{-1}$ to $B_{n-2}=e^{-R}$. For $\ell\ge B_{-1}$, the existing unconstrained GLS design is feasible: $w=K^{-1}\mathbf1/I_0$, with $E_*=1/I_0$.

For $e^{-R}<\ell<B_{-1}$, select $k$ such that $B_k\le\ell\le B_{k-1}$. Only the suffix $k,\ldots,n-1$ is needed; its first weight may be zero at a breakpoint. Put

$$b=\ell/l_k,\qquad c=\frac{1-b}{I_k-1},\qquad z=c-b,$$ $$v_k=\frac1{1+\rho_k},\quad v_j=\frac1{1+\rho_{j-1}}-\frac{\rho_j}{1+\rho_j}\ (k<j<n-1),\quad v_{n-1}=\frac1{1+\rho_{n-2}}.$$
$$w_j=0\ (j<k),\qquad w_j=cv_j-z\mathbf1_{\{j=k\}}\ (j\ge k),\qquad E_*(\ell)=b^2+\frac{(1-b)^2}{I_k-1}.$$

All later suffix weights are strictly positive. At adjacent breakpoint intervals these formulas agree, so the variance frontier is continuous and piecewise quadratic.

Proof: a covariance column makes the active set explicit

Let $K^{(k)}$ be the covariance submatrix on the suffix. The classical tridiagonal inverse gives $v=(K^{(k)})^{-1}\mathbf1$ with the components above and $\mathbf1^Tv=I_k$; each component is positive.

Crucially, $l_{k:n-1}=l_k K^{(k)}e_k$, so $l_{k:n-1}^Tv=l_k$. Therefore the proposed weights have unit mass, memory exactly $\ell$, and potential $u=Kw$ satisfying $u_j+\lambda l_j=c$ on the suffix, where $\lambda=z/l_k\ge0$.

The first weight is nonnegative precisely when $\ell\ge B_k$. For $k>0$, the inequality at the preceding point is equivalent to $z\ge b\rho_{k-1}$, or $\ell\le B_{k-1}$; for $k=0$, $\lambda\ge0$ is equivalent to $\ell\le B_{-1}$.

For any earlier $i<k$, set $d=t_k-t_i$. Since $u_i=be^{-d}$,

$$u_i+\lambda l_i-c=(e^d-1)(z-be^{-d})\ge0,$$

because $e^{-d}\le\rho_{k-1}$. The identity $I_{k-1}=I_k+(1-\rho_{k-1})/(1+\rho_{k-1})$ proves that the successive budget intervals meet; their widths are positive since $I_k>1$ and, for $k>0$, $\rho_{k-1}\rho_k<1$.

Hence all feasible competitors $\widetilde w$ satisfy $(Kw)^T\widetilde w\ge c-\lambda\ell=w^TKw$. With $\delta=\widetilde w-w$,

$$\widetilde w^TK\widetilde w-w^TKw\ge\delta^TK\delta\ge0.$$

Strict positive definiteness follows from the Markov covariance determinant $\det K=\prod_j(1-\rho_j^2)>0$, applied also to every leading principal submatrix. This proves uniqueness; $w^TKw=c-\lambda\ell$ simplifies to the boxed expression.

Implementation and exact example

Compute all $I_k$, scan the breakpoints, then form one suffix of weights: $O(n)$ arithmetic operations and $O(n)$ storage. The certificate supplies this solver and two linear recurrences for $Kw$, avoiding dense matrices even during large-grid validation.

For $t=\log(1,2,3,5,8)$ and budget $\ell=1/6$, the exact optimizer is

$$w=(0,0,11/100,1/4,16/25),\qquad E_*=77/100.$$

The full breakpoint sequence is $(780/1571,260/1051,52/281,13/89,1/8)$. Eleven exact-rational cases verify all feasibility and potential inequalities, including every transition. Independent exact path enumeration checks the mean/variance identities, and a Gaussian-mixture calculation checks the pooled coverage bound.

Another 288 floating-point cases check the KKT conditions and dense/recurrence identities, with 20 independent constrained quadratic-program comparisons. On a 100001-point grid over $[0,8]$ at budget $0.005$, the first active time is $3.61464000$ and normalized energy $0.3368964879$.

Literature and scope

Generalized least squares and the tridiagonal exponential-kernel weights are classical; the existing calibration design note discusses the correlated-observation literature. The added memory constraint and suffix certificate are derived above; no priority claim is made for GLS or covariance inversion.

This is an exact fixed-grid, two-state stationary-variance result; times are not optimized, and estimated rates or data-adaptive weights are not covered. The numerical implementation uses floating-point arithmetic unless given exact rational decays and budgets; no uniform numerical-error bound over collapsing gaps or extreme exposures is asserted.

In particular, these are model-based population bounds, not finite-calibration conditional validity. An ordinary weighted empirical quantile does not acquire conformal rank validity from this variance calculation.

Finite-memory likelihood budgets

A positive restarted-filter approximation with an explicit error bound for every panel length.

Kernel assumption and approximation

For a fixed observed path $x_0,\ldots,x_N$, let $K_k=K(x_k,x_{k+1})$ be its nonnegative regime-resolved density matrices. Fix a strictly positive probability row $\pi$, put $P=\mathbf1\pi$, and suppose positive scalar reference densities $p_k$ satisfy the quantitative bound

$$\max_{k<N}\|K_k/p_k-P\|_\infty\le\delta<\frac13,\qquad \|A\|_\infty=\max_i\sum_j|A_{ij}|,\qquad \rho=\frac{2\delta}{1-\delta}<1.$$

This is a relative matrix-kernel condition, not merely a mixing-rate assumption for the latent chain. Let $F_k(\nu)=\nu K_k/(\nu K_k\mathbf1)$ and start the exact filter from any specified probability row $\nu_0$. Write $\ell_F=\sum_{k<N}\log(\nu_kK_k\mathbf1)$, where $\nu_{k+1}=F_k(\nu_k)$.

For an integer memory length $r\ge0$, set $b_k=\max(0,k-r)$. Form $\widehat\nu_k$ by applying $F_{b_k},\ldots,F_{k-1}$ to $\nu_0$ if $b_k=0$, and to $\pi$ otherwise. The restarted log likelihood is

$$\ell_r=\sum_{k<N}\log(\widehat\nu_kK_k\mathbf1).$$

All predictive factors are strictly positive. When the $K_k$ belong to genuine observation-kernel families, each predictive factor integrates to one, so their product is also a normalized path law conditional on $x_0$. The first $r+1$ predictive factors retain the specified initial prior exactly.

An explicit panel-length bound

$$|\ell_F-\ell_r|\le\frac{(N-r-1)_+}{2}\,\rho^{r+2},\qquad (a)_+=\max(a,0).$$

The constant does not depend on $N$, the number of regimes or the starting prior. For a stationary start, $r=0$ is the stationary-start composite likelihood, with error at most $(N-1)\rho^2/2$. One retained interval, $r=1$, reduces this to $(N-2)_+\rho^3/2$.

If $\delta\le C/m$ uniformly over a specified observation set, fixed memory $r$ gives $|\ell_F-\ell_r|=O(Nm^{-r-2})$ there, with a constant independent of panel length. Thus $N=o(m^{r+2})$ suffices for an absolute log-likelihood gap tending to zero, and $N=o(m^{r+1})$ for a gap $o(m^{-1})$. These are deterministic approximation statements, not estimator-efficiency or statistical-coverage theorems.

Proof from the filter update

Write $E_k=K_k/p_k-P$ and $e_k=E_k\mathbf1$. For every probability row $\nu$, the normalizer $1+\nu e_k$ lies in $[1-\delta,1+\delta]$ and

$$F_k(\nu)=\frac{\pi+\nu E_k}{1+\nu e_k},\qquad \|F_k(\nu)-\pi\|_1\le\rho.$$

Subtracting two updates gives the exact identity

$$F_k(\nu)-F_k(\mu)= \frac{(\nu-\mu)E_k-[(\nu-\mu)e_k]F_k(\mu)}{1+\nu e_k}.$$

Nonnegativity makes $\|F_k(\mu)\|_1=1$, hence the map is $\rho$-Lipschitz in row $\ell^1$ norm. The corresponding predictive log densities obey

$$|\log(\nu K_k\mathbf1)-\log(\mu K_k\mathbf1)| \le\frac{\delta}{1-\delta}\|\nu-\mu\|_1=\frac\rho2\|\nu-\mu\|_1.$$

For $k>r$, the exact filter at the restart boundary $b_k\ge1$ is within $\rho$ of $\pi$. Applying $r$ contractive updates gives $\|\nu_k-\widehat\nu_k\|_1\le\rho^{r+1}$. The log bound then gives $\rho^{r+2}/2$ per remaining factor; summing proves the theorem.

Two-transition blocks give the first correction

With $\nu_0=\pi$, put $s_k=\pi K_k\mathbf1$. The $r=1$ construction has the explicit block formula

$$\ell_1=\ell_C+\sum_{k=1}^{N-1} \log\frac{\pi K_{k-1}K_k\mathbf1}{s_{k-1}s_k}.$$

Each block uses two transitions, hence three consecutive observations in the diffusion model; it is not an ordinary two-observation marginal. If $K_k=p_kP+m^{-1}K_{1,k}+O(m^{-2})$ uniformly, its leading added coefficient is

$$m^{-2}\sum_{k=1}^{N-1} \frac{[\pi K_{1,k-1}-(\pi K_{1,k-1}\mathbf1)\pi]K_{1,k}\mathbf1}{p_{k-1}p_k}.$$

This is the second-order coefficient on the likelihood page, now represented by positive finite blocks with an explicit panel remainder. The construction still uses model-specific regime-resolved kernels; it is not a way to recover them from unlabelled pair frequencies without assumptions.

The memory orders are sharp for positive kernels

Take two states, $\pi=(1/2,1/2)$, $P=\mathbf1\pi$, $A=\tfrac12\left(\begin{smallmatrix}1&1\\-1&1\end{smallmatrix}\right)$ and binary observation matrices $K_\pm=(P\pm\varepsilon A)/2$, $0<\varepsilon<1/3$. They are positive, sum to the stochastic matrix $P$, and have relative kernel budget $\delta=\varepsilon$ with $p_\pm=1/2$.

For the all-plus path of length $N=r+2$, let $S_j=\pi(P+\varepsilon A)^j\mathbf1$. Only the final predictive factor differs, so

$$\ell_F-\ell_r=\log\frac{S_{r+2}S_r}{S_{r+1}^2} =-\left(\frac\varepsilon2\right)^{r+2}+O(\varepsilon^{r+3}).$$

Indeed, the first filter coordinate updates by $a\mapsto[1/2+\varepsilon(a-1/2)]/(1+\varepsilon a)$; its derivative is $\varepsilon(1+\varepsilon)/[2(1+\varepsilon a)^2]$, and the initial displacement is $-\varepsilon/4+O(\varepsilon^2)$. Iteration gives the displayed nonzero coefficient for every fixed $r$.

For $r=1$ the ratio is exactly $1-\varepsilon^3/[8(1+\varepsilon)]$. This is a valid edge-emitting hidden Markov model, whose binary observation depends on the incoming and outgoing hidden states. Sharpness is for the stated kernel class, not a claim that every Vasicek parameter choice attains the cubic order.

Context, verification and scope

Conditional composite likelihoods are classical (Lindsay 1988). Filter forgetting is also classical (Le Gland and Mevel 2000); the latter reference's metadata were checked against its authors' Inria team bibliography, but its full text was unavailable. The elementary near-rank-one constants and sharp-order witness are proved here; no uninspected theorem or priority claim is imported.

The certificate checks exact witness coefficients for $r=0,\ldots,4$, exhaustive binary normalization, nonhomogeneous finite-panel budgets, and the existing Vasicek Fourier kernels on a repeated closed observation path. It ends with literal PASS and uses portable tolerances. Floating Fourier evaluations are not certified density enclosures.

A numerical application must include kernel-evaluation error in its budget. A compact-set bound does not cover arbitrary tail observations, and latent endpoint mixing alone does not establish the required relative density bound. No claim concerns conformal conditional coverage, fixed-feature Green–Kubo rank, or maturity-integrated regime counts.

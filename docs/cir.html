CIR with a switching mean level

A square-root intensity whose long-run level follows a hidden regime.

The model

A default intensity, or short rate, $x_t$ follows a square-root (CIR) process whose long-run level is set by a hidden regime $y_t \in \{1, 2\}$:

$$dx_t = \kappa\,(\theta_{y_t} - x_t)\,dt + \sigma\sqrt{x_t}\,dW_t .$$

The volatility parameter $\sigma$ is the same in both regimes.

The regime switches at rate $\lambda$ in each direction. The intensity reverts over $1/\kappa$; the regime changes every $1/\lambda$.

Parameters: $\kappa = 1.5$, $\theta = (0.08, 0.02)$ and $\sigma = 0.15$.

What is computed

The survival probability, or bond price,

$$u_i(t,x) = \mathbb{E}\big[e^{-\int_0^t x_r\,dr} \mid x_0 = x,\ y_0 = i\big].$$

Averaging

When the regime switches infinitely fast the limit is the CIR model with mean level $\bar\theta = \tfrac12(\theta_1 + \theta_2)$ and its classical bond price.

Reduction to a linear system

By the Feynman–Kac formula the prices solve

$$\partial_t u_i = \kappa(\theta_i - x)\,\partial_x u_i + \tfrac12\sigma^2x\,\partial_{xx}u_i - x\,u_i + \sum_j Q_{ij}\,u_j, \qquad u_i(0,x) = 1.$$

Try $u_i = e^{-B(t)x}a_i(t)$. The square-root diffusion now contributes $\tfrac12\sigma^2B^2\,x$, so the terms in $x$ cancel when

$$B' = 1 - \kappa B - \tfrac12\sigma^2B^2, \qquad B(0) = 0 .$$

This Riccati equation involves $\kappa$ and $\sigma$ but not $\theta$, so one $B$ serves every regime:

$$B(t) = \frac{2\,(e^{ht} - 1)}{(h+\kappa)(e^{ht}-1) + 2h}, \qquad h = \sqrt{\kappa^2 + 2\sigma^2}.$$

So $u_i = e^{-B(t)x}a_i(t)$ with $a' = (Q + \operatorname{diag} g)a$, $a(0) = \mathbf 1$ and $g_i(t) = -\kappa\,\theta_i\,B(t)$. If $\sigma$ also switched, $B$ would differ between regimes and the state would not factor out.

The expansion

Let the regime switch at rate $\lambda$ in each direction, and write

$$\varepsilon = \frac1\lambda, \qquad \bar g = \tfrac12(g_1 + g_2), \qquad \tilde g = \tfrac12(g_1 - g_2),$$

where $g_i = -\kappa\theta_i B$, so that $\tilde g = -\kappa\tilde\theta B$ with $\tilde\theta = \tfrac12(\theta_1 - \theta_2)$. The average $\bar g$ is what the averaged model sees. The half-difference $\tilde g$ measures how much the two regimes disagree.

First order

To first order in $\varepsilon$,

$$a_i(t) = \exp\Big(\int_0^t \bar g + \frac{\varepsilon}{2}\int_0^t \tilde g^{\,2}\Big)\Big(1 \pm \frac{\varepsilon}{2}\,\tilde g(t)\Big) + O(\varepsilon^2),$$

with the upper sign for a start in regime 1. The three factors have separate meanings, explained on the idea page.

  • $e^{\int\bar g}$ is the averaged model.
  • $\frac\varepsilon2\int\tilde g^2$ is half the variance of the fluctuating integral of $g$. It is the same for both starting regimes, and it grows with $t$.
  • The bracket is the memory of the starting regime. The switch stays near its starting state for about $1/(2\lambda)$, which shifts the integral by $\pm\tilde g/(2\lambda)$.

Every order

Add and subtract the two equations for $a_1$ and $a_2$. The mean $m = \tfrac12(a_1 + a_2)$ and the normalized difference $\omega = (a_1 - a_2)/(a_1 + a_2)$ then satisfy

$$\omega' = \tilde g\,(1 - \omega^2) - 2\lambda\,\omega, \qquad \omega(0) = 0,$$ $$\log m(t) = \int_0^t \big(\bar g + \tilde g\,\omega\big), \qquad a_{1,2} = m\,(1 \pm \omega).$$

The first equation has a large restoring term $-2\lambda\omega$: the switch pulls the two regimes together at rate $2\lambda$, while $\tilde g$ pushes them apart. So $\omega$ stays close to the value that balances the two, and expanding in $\varepsilon$ finds that value order by order. Writing $\omega = \sum_n \varepsilon^n\omega_n$ and matching powers gives

$$\omega_1 = \frac{\tilde g}{2}, \qquad \omega_{n+1} = -\frac12\Big(\omega_n' + \tilde g\sum_{i+j=n}\omega_i\,\omega_j\Big).$$

This is the two-state case of the solvability argument: at each order the restoring term can be inverted, which here is a division by $2\lambda$.

The series does not satisfy $\omega(0) = 0$. An initial layer of width about $1/(2\lambda)$ repairs the start and is solved order by order in the same way. The engine page gives the version for any number of regimes.

$B$ is not a sum of exponentials, so the engine holds $g_i$ as a Chebyshev series.

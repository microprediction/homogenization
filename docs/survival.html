Survival under regime switching

Companion to the note on the corrected homogenization expansion.

The hazard rate mean-reverts at speed $\kappa = 2$ towards a level that switches between $\theta_1 = 0.15$ and $\theta_2 = 0.02$, with variance $\sigma_1^2 = 0.0555$ in the first regime and $\sigma_2^2 = 0.0055$ in the second. These are the parameters of the 2020 homogenize example. The upper chart plots the survival probability to time $t$. The lower chart plots each approximation minus the exact solution, which is where the differences show.

What to look for: the averaged curve is the same whichever regime the process starts in, and the exact curve is not. From about $\lambda = 10$ the second-order curve sits on the exact one, and the first-order curve is close behind. The package's first-order error shrinks only like $1/\lambda$, at the rate of the averaged curve, as the convergence demo shows. A second-order error that failed to shrink as $\lambda$ grows would refute the expansion.

The exact solution integrates the two-state linear ODE by fourth-order Runge–Kutta in your browser. The expansions evaluate the formula on the home page. The same code agrees with the Python reference to $10^{-11}$.

Heston with a switching long-run variance

Stochastic volatility whose long-run level follows a hidden regime, and the option prices it implies.

The model

A stock price $S_t = e^{X_t}$ has stochastic variance $v_t$, as in Heston's model, except that the level to which the variance reverts is set by a hidden regime $y_t \in \{1, 2\}$, a calm market and a turbulent one:

$$dX_t = -\tfrac12 v_t\,dt + \sqrt{v_t}\,dW_t, \qquad dv_t = \kappa\,(\theta_{y_t} - v_t)\,dt + \xi\sqrt{v_t}\,dZ_t, \qquad d\langle W, Z\rangle = \rho\,dt .$$

The regime switches at rate $\lambda$ in each direction. The variance reverts over $1/\kappa$; the regime changes every $1/\lambda$.

Parameters: $\kappa = 2$, $\theta = (0.09, 0.02)$, $\xi = 0.4$, $\rho = -0.6$, $v_0 = 0.04$, $S_0 = 100$, zero interest, one year to expiry, $\lambda = 10$, and a start in the turbulent regime.

The quantity

European call prices, through the characteristic function

$$\phi_i(u) = \mathbb{E}\big[e^{iu(X_T - X_0)} \mid v_0,\ y_0 = i\big]$$

and Lewis's formula

$$C = S_0 - \frac{\sqrt{S_0K}}{\pi}\int_0^\infty \operatorname{Re}\big[e^{iu\log(S_0/K)}\,\phi(u - \tfrac i2)\big]\,\frac{du}{u^2 + 1/4}.$$

Averaging

When the regime switches infinitely fast the limit is Heston's model with long-run variance $\bar\theta = \tfrac12(\theta_1 + \theta_2)$ and its closed-form characteristic function.

Reduction to a linear system

The characteristic function solves a Feynman–Kac equation in the log price, the variance and the regime. Try the Heston form $\phi_i = e^{D(t)v_0}\,a_i(t)$. The terms in $v_0$ cancel when

$$D' = -\tfrac12(u^2 + iu) + (\rho\xi iu - \kappa)\,D + \tfrac12\xi^2D^2, \qquad D(0) = 0 .$$

This Riccati equation involves $\kappa$, $\xi$ and $\rho$ but not $\theta$, so one $D$ serves both regimes. Its solution is

$$D(t) = \frac{\kappa - \rho\xi iu - d}{\xi^2}\;\frac{1 - e^{-dt}}{1 - \gamma e^{-dt}}, \qquad d = \sqrt{(\rho\xi iu - \kappa)^2 + \xi^2(iu + u^2)},$$

with

$$\gamma = (\kappa - \rho\xi iu - d)/(\kappa - \rho\xi iu + d).$$

So $\phi_i = e^{D(T)v_0}a_i(T)$ with $a' = (Q + \operatorname{diag} g)a$, $a(0) = \mathbf 1$ and $g_i(t) = \kappa\,\theta_i\,D(t)$, which is complex.

The expansion

Let the regime switch at rate $\lambda$ in each direction, and write

$$\varepsilon = \frac1\lambda, \qquad \bar g = \tfrac12(g_1 + g_2), \qquad \tilde g = \tfrac12(g_1 - g_2),$$

Here

$$g_i = \kappa\theta_i D, \qquad \tilde g = \kappa\tilde\theta D .$$

The average $\bar g$ is what the averaged model sees. The half-difference $\tilde g$ measures how much the two regimes disagree.

First order

To first order in $\varepsilon$,

$$a_i(t) = \exp\Big(\int_0^t \bar g + \frac{\varepsilon}{2}\int_0^t \tilde g^{\,2}\Big)\Big(1 \pm \frac{\varepsilon}{2}\,\tilde g(t)\Big) + O(\varepsilon^2),$$

with the upper sign for a start in regime 1. The three factors have separate meanings, explained on the idea page.

  • The factor below is the averaged model: $$e^{\int_0^t \bar g} .$$
  • The term below is half the variance of the fluctuating integral of $g$: $$\frac\varepsilon2\int_0^t\tilde g^{\,2} .$$ It is the same for both starting regimes, and it grows with $t$.
  • The bracket is the memory of the starting regime. The switch stays near its starting state for about $1/(2\lambda)$, which shifts the integral by $\pm\tilde g/(2\lambda)$.

Every order

Add and subtract the two equations for $a_1$ and $a_2$. The mean $m = \tfrac12(a_1 + a_2)$ and the normalized difference $\omega = (a_1 - a_2)/(a_1 + a_2)$ then satisfy

$$\omega' = \tilde g\,(1 - \omega^2) - 2\lambda\,\omega, \qquad \omega(0) = 0,$$ $$\log m(t) = \int_0^t \big(\bar g + \tilde g\,\omega\big), \qquad a_{1,2} = m\,(1 \pm \omega).$$

The first equation has a large restoring term $-2\lambda\omega$: the switch pulls the two regimes together at rate $2\lambda$, while $\tilde g$ pushes them apart. So $\omega$ stays close to the value that balances the two, and expanding in $\varepsilon$ finds that value order by order. Write

$$\omega = \sum_n \varepsilon^n\omega_n$$

and match powers of $\varepsilon$:

$$\omega_1 = \frac{\tilde g}{2}, \qquad \omega_{n+1} = -\frac12\Big(\omega_n' + \tilde g\sum_{i+j=n}\omega_i\,\omega_j\Big).$$

This is the two-state case of the solvability argument: at each order the restoring term can be inverted, which here is a division by $2\lambda$.

The series does not satisfy $\omega(0) = 0$. An initial layer of width about $1/(2\lambda)$ repairs the start and is solved order by order in the same way. The engine page gives the version for any number of regimes.

The engine holds the complex $g_i$ as Chebyshev series.

Explicit formulas

For Heston every term up to second order is in closed form. Write

$$b = \kappa - \rho\xi iu, \qquad d = \sqrt{b^2 + \xi^2(iu + u^2)}, \qquad \gamma = \frac{b - d}{b + d},$$

so that the regime-free coefficient and its derivative are

$$D(t) = \frac{b - d}{\xi^2}\;\frac{1 - e^{-dt}}{1 - \gamma e^{-dt}}, \qquad D'(t) = -\tfrac12(u^2 + iu) - b\,D(t) + \tfrac12\xi^2 D(t)^2 .$$

Step 1: the forcing

The forcing is proportional to $D$, so its average and half-difference are

$$\bar g(t) = \kappa\,\bar\theta\,D(t), \qquad \tilde g(t) = \kappa\,\tilde\theta\,D(t), \qquad \bar\theta = \tfrac12(\theta_1 + \theta_2),\quad \tilde\theta = \tfrac12(\theta_1 - \theta_2).$$

Step 2: the two integrals

The averaged exponent needs $\int D$, the Heston integral. With $L(t) = \log\big((1 - \gamma e^{-dt})/(1 - \gamma)\big)$,

$$\int_0^t D(s)\,ds = \frac{1}{\xi^2}\Big((b - d)\,t - 2L(t)\Big).$$

The first correction needs $\int D^2$. Substituting $E = e^{-ds}$ and splitting into partial fractions gives

$$\int_0^t D(s)^2\,ds = \Big(\frac{b-d}{\xi^2}\Big)^2\Big[t + \frac{\alpha}{\gamma d}\,L(t) - \frac{\beta}{\gamma d}\Big(\frac{1}{1 - \gamma e^{-dt}} - \frac{1}{1 - \gamma}\Big)\Big],$$ $$\alpha = \frac{\gamma^2 - 1}{\gamma}, \qquad \beta = 2\gamma - 2 - \alpha .$$

Step 3: the recursion to second order

The recursion gives $\omega_1 = \tilde g/2$ and $\omega_2 = -\omega_1'/2 = -\tilde g'/4$. The second-order term of the exponent is

$$\int_0^t \tilde g\,\omega_2 = -\frac14\int_0^t \tilde g\,\tilde g' = -\frac18\,\tilde g(t)^2,$$

because $\tilde g(0) = \kappa\tilde\theta D(0) = 0$.

Step 4: the result

Every term, written out in the model's parameters:

$$\begin{aligned} \phi_{1,2}(u) = \;&\exp\Big(v_0\,D + \kappa\bar\theta\,I_1 + \frac{\varepsilon}{2}\,\kappa^2\tilde\theta^2\,I_2 - \frac{\varepsilon^2}{8}\,\kappa^2\tilde\theta^2\,D^2\Big) \\ &\times\Big(1 \pm \frac{\varepsilon}{2}\,\kappa\tilde\theta\,D \mp \frac{\varepsilon^2}{4}\,\kappa\tilde\theta\,D'\Big) + O(\varepsilon^3), \end{aligned}$$ $$\begin{aligned} D &= \frac{b - d}{\xi^2}\,\frac{1 - E}{1 - \gamma E}, \\ D' &= -\tfrac12(u^2 + iu) - b\,D + \tfrac12\xi^2 D^2, \\ I_1 &= \frac{(b - d)\,T - 2L}{\xi^2}, \\ I_2 &= \Big(\frac{b - d}{\xi^2}\Big)^2\Big[\,T + \frac{\alpha L}{\gamma d} - \frac{\beta}{\gamma d}\Big(\frac{1}{1 - \gamma E} - \frac{1}{1 - \gamma}\Big)\Big], \\ L &= \log\frac{1 - \gamma E}{1 - \gamma}, \qquad E = e^{-dT}, \\ b &= \kappa - \rho\xi iu, \qquad d = \sqrt{b^2 + \xi^2(iu + u^2)}, \qquad \gamma = \frac{b - d}{b + d}, \\ \alpha &= \frac{\gamma^2 - 1}{\gamma}, \qquad \beta = 2\gamma - 2 - \alpha . \end{aligned}$$

Here $D = D(T)$ is the coefficient of the starting variance in the log characteristic function, the same as in Heston's model. $I_1$ and $I_2$ are the closed forms of $\int_0^T D$ and $\int_0^T D^2$. The upper sign is for a start in regime 1. The initial layer adds a term of size $\varepsilon^2 e^{-2\lambda T}$ to the bracket, which is below $10^{-10}$ here.
